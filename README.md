# مصحف المراجعة

مصحف مستقل (PWA) لتعليم أخطاء الحفظ والتلاوة على مستوى الكلمة. الأخطاء تتحفظ على الجهاز (IndexedDB) ومش بتتمسح لما تقفل التطبيق.

## المميزات
- المصحف كامل ٦٠٤ صفحة بخط مصحف المدينة (QCF4)، تقليب بالسحب.
- لمس أي كلمة ← نوع الخطأ: حفظ / تشكيل / تجويد / تردد ووقف، وعدّاد لتكرار الخطأ.
- وضع تعليم سريع (لمسة واحدة بنوع افتراضي) + تراجع.
- إخفاء الأخطاء للتسميع من غير ما تشوفها.
- لوحة الكلمة فيها ٣ تبويبات لدراسة الآية:
  - **التفسير**: «المختصر في التفسير» (مركز تفسير للدراسات القرآنية).
  - **معاني الكلمات**: «السراج في بيان غريب القرآن» (د. محمد الخضيري)، ومعنى الكلمة الملموسة بيظهر الأول.
  - **المتشابهات**: الآيات اللي بتشتبه بالآية دي، والكلمات اللي بتفرق ملوّنة، والضغط ينقلك للآية مع زرار رجوع.
- البحث في نص القرآن: بيتجاهل التشكيل والهمزات وفرق الرسم العثماني والإملائي، مع خيار «كلمات كاملة».
- مواضع القراءة (الحفظ، المراجعة، أو أي موضع تضيفه): كل موضع بيفتكر آخر صفحة، والموضع الحالي بيمشي مع التقليب.
- علامات للصفحات مع ملاحظة اختيارية.
- قائمة الأخطاء: فلترة بالنوع، ترتيب بالمصحف/الأكثر تكرارًا/الأحدث، والضغط ينقلك للكلمة.
- فهرس السور والأجزاء والأحزاب والأرباع مع عدد الأخطاء في كل منها، وانتقال برقم الصفحة.
- علامة ۞ في الهامش عند بداية كل ربع (رقم الحزب أو ¼ ½ ¾)، والحزب ظاهر في أعلى الصفحة. بيانات الأرباع من حزمة quran-meta.
- وضع ليلي: تلقائي حسب الجهاز، أو فاتح/ليلي من الإعدادات.
- تلاوة كل آية بصوت قارئ تختاره (الحصري، المنشاوي، عبد الباسط، العفاسي، …) من everyayah.com: تكرار الآية ١/٢/٣/٥ أو على طول، والتشغيل المتواصل بيقلّب الصفحة لوحده، والآية اللي بتتقري بتتلوّن.
- التلاوة بدون نت: أي آية بتسمعها بتتحفظ على الجهاز، وتقدر تحمّل سورة أو جزء كامل بصوت القارئ من الإعدادات.
- يشتغل بدون إنترنت، مع زرار لتحميل المصحف كامل.
- تصدير/استيراد نسخة احتياطية JSON (الأخطاء والمواضع والعلامات).

## البنية
| الملف | الوظيفة |
|---|---|
| `index.html`, `app.css` | الواجهة |
| `js/app.js` | منطق الواجهة وأنواع الأخطاء (`TYPES`) |
| `js/store.js` | التخزين (IndexedDB مع بديل localStorage) |
| `js/mushaf.js` | رسم صفحة المصحف وتحميل الخطوط |
| `js/text.js` | نص الآيات: التطبيع والبحث ومقارنة المتشابهات |
| `js/audio.js` | التلاوة: القرّاء ومشغّل الآيات (تكرار، تواصل، بسملة، أزرار الشاشة المقفولة) |
| `js/audio-cache.js` | حفظ ملفات التلاوة على الجهاز (Cache API) للاستماع بدون نت |
| `js/quran.js` | بيانات السور والصفحات والأجزاء |
| `sw.js` | العمل بدون إنترنت |
| `data/`, `fonts/`, `fontmap.json` | بيانات الصفحات والخطوط (منقولة من quran-halaqa/mushaf) |
| `data/tafsir/mukhtasar/` | المختصر في التفسير مقسّم على الصفحات — بيتولّد بـ `python3 tools/fetch-tafsir.py` من QuranEnc.com |
| `data/text.json`, `data/gharib/`, `data/mutashabihat.json` | نص الآيات ومعاني الكلمات والمتشابهات — بيتولّدوا بـ `python3 tools/build-data.py` |

## مصادر البيانات
- المختصر في التفسير — مركز تفسير للدراسات القرآنية، عن طريق QuranEnc.com.
- السراج في بيان غريب القرآن — د. محمد بن عبد العزيز الخضيري، عن طريق [Tafsir-Kalimat-DB](https://github.com/Muhammad95959/Tafsir-Kalimat-DB).
- المتشابهات — [Quran Mutashabihat Data](https://github.com/Waqar144/Quran_Mutashabihat_Data) (CC0)، مبنية على عمل القارئ إدريس العاصم.
- نص الكلمات — حزمة [quran-qcf4](https://www.npmjs.com/package/quran-qcf4) (MIT)، بنفس ترقيم كلمات المصحف.

## إضافة نوع خطأ جديد
سطر في `TYPES` داخل `js/app.js`، ولون `--t-<key>` و `.w.m-<key>` في `app.css`.

## التشغيل محليًا
```
python3 -m http.server 8000
```
ثم افتح http://localhost:8000
